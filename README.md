# -ESP32P4-
本项目面向厂区、园区及实验场所等安全巡检场景，设计并实现了一套基于 ESP32-P4 的多端协同智能巡检系统。系统以智能巡检车为核心，集成自主循迹、路径点巡检、可见光异常识别、红外热成像监测、公网远程监管和 AI 智能诊断等功能。硬件上采用“左眼可见光、右眼热成像”的双眼协同结构，其中热成像模块支持快拆，可在高温报警后拆下作为手持设备进行现场复核。软件上构建了车端执行、边缘识别、云端管理和语音交互协同链路，并遵循 Producer—Consumer—Saver 理念，实现数据采集、分析处理与结果保存闭环。系统可通过网页和 M5Stick 语音终端完成状态查询、任务控制及安全隐患诊断，具有较强的创新性、实用性和推广价值。
